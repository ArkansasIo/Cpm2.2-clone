# HELP

Built-in command reference for the CP/M-style environment.

`DIR` list files
`TYPE FILE.TXT` display text
`COPY A.TXT B.TXT` copy a file
`ERA FILE.TXT` erase a file
`REN NEW.TXT=OLD.TXT` rename a file
`STAT` show storage statistics
`PIP` transfer files between logical devices
`ED FILE.TXT` edit text
`SUBMIT JOB.SUB` execute a command batch
`ASM PROGRAM.ASM` assemble an application image
`LOAD PROGRAM.COM` load an application
`SAVE PROGRAM.COM` save an application image
`BASIC` start BASIC
`CALC` start calculator
`CLOCK` show CMOS/RTC time
`HELP` show this page
