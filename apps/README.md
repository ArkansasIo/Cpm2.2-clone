# Built-in CP/M-era applications

The emulator includes original small applications modeled on the kinds of utilities commonly used on CP/M systems in the early and mid-1980s. These are compatibility-style recreations, not copies of historical proprietary programs.

Planned/implemented application set:

- `DIR` — directory browser with CP/M-style 8.3 names.
- `TYPE` — text-file viewer.
- `COPY` — file copy utility.
- `ERASE` — file deletion utility.
- `REN` — rename utility.
- `STAT` — disk/file statistics.
- `PIP` — peripheral/file transfer utility in a simplified CP/M style.
- `ED` — line-oriented text editor.
- `SUBMIT` — command batch processor.
- `ASM` — small educational assembler for the emulator's boot/application format.
- `LOAD` — program loader with the retro/Morse storage sound layer.
- `SAVE` — program/image saver with the retro/Morse storage sound layer.
- `BASIC` — small interactive BASIC-style interpreter.
- `CALC` — integer/scientific calculator.
- `CLOCK` — CMOS/RTC clock display.
- `HELP` — built-in command/application manual.

The goal is to make the emulator feel like a self-contained 1980s microcomputer environment while remaining portable to desktop and Android APK targets.
