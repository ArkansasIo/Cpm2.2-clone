# Desktop and XMB Specification

## Desktop shell
The desktop follows an original classic Ubuntu-inspired visual language: top panel, launcher/dock, task switching, terminal, file manager, settings, notifications, system indicators, and movable application windows.

## XMB
The XMB-style navigation is an optional centered overlay. Categories are arranged horizontally, with items arranged vertically beneath the active category. It supports keyboard, mouse, touch, and controller navigation. Position, visibility, scale, and input mode are persistent user preferences.

## Panels
Every panel exposes a model/view/controller boundary so the same service layer can be rendered by desktop and mobile front ends.

## Mobile
Android and iOS use the same application services and core runtime while adapting navigation, windowing, touch input, lifecycle, storage permissions, and display density to the platform.
